# Text-File-Compression-Huffman-Tree

Introduction

File compression is a technique used to reduce the size of a file. Huffman Coding is a lossless compression algorithm that uses character frequency to generate binary codes. Frequently occurring characters get shorter codes, while less frequent characters get longer codes.

Problem Statement

To develop a text file compression system using Huffman Coding that reduces the size of text data by assigning binary codes based on character frequency.

Objectives

- To understand the Huffman Tree data structure.
- To calculate the frequency of each character.
- To generate binary codes for characters.
- To compress text using Huffman Coding.
- To decompress the encoded text without losing data.

Technology Used

- Programming Language: Python
- Data Structure: Binary Tree and Priority Queue
- Algorithm: Huffman Coding
- Platform: Visual Studio Code

Advantages

- Reduces the number of bits needed to represent text.
- Uses lossless compression, so the original text can be recovered.
- Assigns shorter codes to frequently occurring characters.
- Demonstrates the practical use of binary trees and priority queues.
